# V4.90 — Vishwananda Chalisa, new melody

## Source decision (important)

The two supplied PDFs are **different compositions**, not interchangeable layouts.
The May-2023 text has the Mauritius/parents, childhood puja/Babaji and Hari Bhakta
Sampradaya verses. The new-melody chord score and the supplied recording instead
have the Rama/Narasimha, Radha/Krishna, Garuda/Shesha and Ranganath verses.
Hindi ASR of the supplied recording corroborates the chord-score sequence.

The existing `vchalisa` entry and its position in **More / Weitere** are unchanged.
Its active lyrics and line-by-line chords now follow the **new-melody score**,
including Am, Dm, C/G, C/B and three distinct closing chord progressions. The
page-boundary split in the Bhagirath/Gajendra stanza is joined. There are 31
playback blocks, including the repeated refrains and coda. Old files remain in
history/the repository but are not offered as an alternate recording.

The May-2023 text's unique verses are deliberately **not falsely aligned** with
this recording. Matching English passages are taken from that PDF. English for
score-only passages is a literal translation, explicitly `(von Grok ergänzt)`.
DE/FR/ES/RU/HI/PT/CZ translations are derived from English and bear that same
label. These machine-written translations have not had a human language review.

## Sound processing

Only the transformed recording is added. The supplied original is not committed.
The complete stereo mix (not an isolated vocal stem) receives a subtle upward
formant/timbre shift: Rubber Band +1 semitone with shifted formants, followed by
−1 semitone preserving the shifted formants. Both stages use tempo=1. Net musical
pitch remains unchanged; **no chord transposition is required**.

Loudness target −18 LUFS, true-peak target −2 dBTP, post-resampling peak limiter;
44.1 kHz stereo MP3 at 160 kbit/s. The final length is padded/trimmed to the input's
decoded duration (569.02825 s; MP3 container/decoder rounding can differ slightly).
No source metadata or source MP3 is published. Signal measurements are not a
substitute for subjective listening; no human listening approval is claimed.

## Reproducible browser regression

Install Playwright/Chromium in a local tooling directory (not committed), serve
this repository, then run e.g.:

```sh
python3 -m http.server 8919 --bind 127.0.0.1
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs node tests/v490.mjs
```

`URL`, `OUTPUT_DIR` and `ONLY` may be set. The suite covers Desktop, Galaxy S9+
tab, emulated Galaxy S9+ standalone, and 360 px. Standalone emulation is **not**
a real installed Android PWA or an Android hardware test. Assertions cover actual
media-time advancement, exact new recording URL, cached 206 responses, 54/54
inventory, zero second-download MP3 requests, a legacy-cache 53/54→54/54 repair
fetching only the new recording, all translation fields/labels, chord types,
ten sync checkpoints, fullscreen, navigation, 10-second layout stability, and
Chalisa playback after offline page reload. Screenshots/results are written to
the tooling artifact directory, not the repository.
